# 8i

> 8i is a volumetric video company that captures, transforms, and streams photorealistic
> holograms of real people for AR, VR, WebXR, and mobile experiences. It sells ASPX hologram
> capture stages, a transformation pipeline built on its PAT mesh-based codec (MPD/MPEG-DASH,
> glTF and FBX outputs), and a CDN streaming layer with shareable links, DRM and viewer
> analytics. Integration is client-side: the 8i WebPlayer (volcap-player.js), the 8i Unity
> Plugin, and the 8i Unreal Plugin. 8i publishes no HTTP API, no OpenAPI, and no other
> machine-readable API contract.

## Developer surface

- [8i WebPlayer documentation](https://8i.github.io/embeddable_webplayer/#/): Embeddable browser player for PAT volumetric content — A-Frame `hologram` component, THREE.js `EightiHologram` class, attributes, properties, methods, events, and the dated changelog.
- [8i WebPlayer library](https://player.8i.com/release/latest/volcap-player.js): The CDN-hosted player bundle. Pin a version with `https://player.8i.com/release/${VERSION}/volcap-player.js`.
- [8i WebPlayer demo](https://player.8i.com): Live demo of the latest player release.
- [8i Unity Plugin documentation](https://8iunityplugin.readthedocs.io/en/latest/): Version 1.8.0f1. HVR and PAT component sets, the shared `IEighti` interface, per-platform notes for Android, iOS, Linux, macOS and Windows.
- [8i Unity Plugin quick start](https://8iunityplugin.readthedocs.io/en/latest/Quickstart.html): Creating an HvrActor or PatActor, creating a build, building for VR and AR.
- [8i Unreal Plugin documentation](https://8iunrealplugin.readthedocs.io/en/latest/): Version 0.6.1. PATActor and PATAsset classes, installation, known issues, release notes.
- [8i GitHub organization](https://github.com/8i): Mostly upstream forks (Draco, GStreamer, FFmpeg, dash.js, Qt); the first-party repositories are the Unity and Unreal plugin documentation sources.

## Products

- [Capture](https://8i.com/capture/): ASPX hologram stages — cameras, lights, cables, sync boxes, computers, calibration and recording software.
- [Transform](https://8i.com/transform/): Encoding captures into PAT, with FBX and glTF mesh outputs and Maya interoperability.
- [Stream](https://8i.com/stream/): Hologram asset management, shareable links, CDN distribution, DRM, VOD and real-time playback, viewer analytics; direct integrations with Unity, Unreal and 8th Wall.
- [ASPX Hologram Stages](https://8i.com/aspx-hologram-stages/): The capture stage product line.

## Notes

- Generated by API Evangelist on 2026-08-06 from 8i's public surface. 8i does not publish an llms.txt of its own (https://8i.com/llms.txt returned 404).
- There is no OpenAPI, AsyncAPI, GraphQL SDL, Postman collection, MCP server, or A2A agent card for 8i. The only machine-readable contract in the delivery path is the MPEG-DASH MPD manifest per hologram asset.
